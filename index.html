Problem

온도 경보는 이미 늦습니다

  • 냉동고 온도가 기준을 벗어났을 때는 이미 압축기·냉매·콘덴서에 문제가 진행된 뒤입니다.

  • 같은 조건에서 관리 기준 온도 경보는 느린 고장의 40%만 잡았고, 그것도 AI보다 2~3주 늦었습니다 시뮬레이션

  • 제약·백신·시료처럼 온도 이탈 = 폐기인 현장에서는 이 2~3주가 손실을 결정합니다.

고장 감지율 비교 시뮬레이션

Edge AI 게이트웨이100%
Isolation Forest (오경보 0 기준)68%
온도 기준 경보40% · 2~3주 늦음
Isolation Forest란? 이상탐지(Anomaly Detection) 분야에서 가장 널리 쓰이는 대표적인 머신러닝 기법입니다. 고장 데이터 없이 정상 데이터만으로 학습해, 다른 값들과 동떨어진 데이터를 이상으로 판단합니다. 설비 예지보전 연구와 제품에서 기준 비교 대상으로 흔히 쓰입니다.

같은 데이터 기준. Isolation Forest는 고장 40대 전체 감지율(1년 학습), 온도 기준 경보는 느린 고장 대상.

Solution

냉동고에 붙이고, 센서만 연결

기존 냉동고를 바꿀 필요가 없습니다. 게이트웨이를 옆면에 걸고 전류·도어·온도 센서를 연결하면 그날부터 학습을 시작합니다.

  1. 게이트웨이냉동고 옆면 또는 벽에 고정 (VESA 75 / M4 나사)
  2. 경광등DO 릴레이 출력
  3. 도어 접점DI 입력, 열림 횟수와 시간
  4. 고내 온도 센서4-20mA 입력
  5. CT 클램프압축기 전류, 전선 피복 그대로 집기만 하면 됨
  6. LAN웹 화면 · REST API(JSON) · 서버 연동

How it works

MCU 하나로 동작하는 자체 개발 AI 엔진

고장 사례를 수천 건 모아 학습시키는 딥러닝 방식이 아닙니다. 냉동 원리를 아는 물리 모델, 냉동고마다 정상을 배우는 학습 모델, 원인과 시기를 짚는 판단 모델. 세 모델이 차례로 판단하는 3중 판단 엔진입니다.

냉동 사이클이 한 번 돌 때마다 설비 상태를 나타내는 6가지 지표를 계산합니다.

02학습 모델

냉동고마다 '정상'을 배운다

같은 기종이라도 냉동고마다 정상은 다릅니다. 외기 온도에 따른 정상 범위를 30일 단위로 쌓아 사계절(1년) 기준을 완성합니다. 고장이 의심되는 달은 학습에서 제외합니다.

03판단 모델

무엇이, 언제 문제인지 짚는다

정상에서 얼마나, 어느 방향으로 벗어났는지로 이상 정도와 원인을 추정하고, 7일 추세로 점검이 필요한 시점을 예상합니다.

오판 방지 ① 규칙 검사압축기 정지 · 기동 실패 · 가동률 85% 초과처럼 즉시 알려야 할 상황은 AI 판단과 별도로 바로 경보합니다.
오판 방지 ② 센서 자기 진단단선 · 값 고정 · 튐 · CT 빠짐을 구분해, 센서 고장을 설비 고장으로 잘못 경보하지 않습니다.

Design · VISOR 케이스

모니터링만 하는 시대는 지났습니다

이제 장비가 스스로 판단하는 시대입니다. 그 변화를 외관에도 담았습니다. 계단형 바이저 창과 큰 챔퍼로 단정하게, 현장 어디서든 상태가 한눈에 들어오도록 설계했습니다.

  • PCB 앞판 — 플라스틱 대신 FR4 PCB를 앞판으로. 검정 무광 위에 흰 글씨, 로고·창 테두리는 금(ENIG)
  • 단자 이름 인쇄 — 앞판에 단자·핀 이름이 그대로 적혀 있어 설명서 없이 배선
  • 버튼 — 12mm 금속 버튼 2개 (NEXT · ACK)
  • 본체 · 설치 — SLA 레진 + 황동 인서트, 뒷면 VESA 75 규격으로 벽·냉동고 옆면·시중 브래킷 고정
